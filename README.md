# 🐍 دورة بايثون المكثفة — Python Crash Course (AR)

ترجمة وتعريب كامل لكتاب **Python Crash Course** بقلم إريك ماتيس، مع مسار إضافي كامل
لمهندسي الذكاء الاصطناعي التطبيقي (Applied AI Engineer).

## 📚 المحتوى

- **📘 الجزء الأول:** أساسيات بايثون (الفصول 1–11)
- **⚙️ Core Engineering:** Python Advanced، AsyncIO، SQL، PostgreSQL، Linux، Git، Docker
- **🚀 Backend + AI:** FastAPI، Redis، أساسيات الذكاء الاصطناعي
- **🧠 Agent Engineering:** RAG، Vector Databases، Ollama، LangChain، LangGraph، وكلاء الذكاء الاصطناعي
- **⚙️ MLOps Foundations:** MLflow، CI/CD، AWS
- **🚀 المشاريع:** 6 مشاريع متكاملة (Pygame → Django → Data API → AI Chat → AI Platform)
- **🗺️ الخطة الأسبوعية:** خريطة تفاعلية لـ 104 أسابيع لتصبح Applied AI Engineer
