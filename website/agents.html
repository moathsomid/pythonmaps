وكلاء الذكاء الاصطناعي (Agents)

أنماط الوكلاء، الأدوات، والتخطيط — بما فيها وكيل تحليل البيانات

← العودة إلى الرئيسية

الوكيل (Agent) ليس مجرد نموذج LLM. الوكيل يملك: نموذجاً يفكر، أدوات ينفذ بها (بحث، حساب، استدعاء API)، وحلقة يقرر فيها ما الخطوة التالية. بدل إجابة واحدة، الوكيل يخطط وينفذ ويكرر حتى يكمل المهمة.

الفرق الجوهري: التطبيق التقليدي = تدفق ثابت. الوكيل = حلقة قرار: فكّر ← نفّذ أداة ← راقب النتيجة ← قرر مرة أخرى. هذا يفتح مهام لم تكن ممكنة برمجياً بسهولة.

1. نمط ReAct — الأساس

النمط الأشهر: Reasoning + Act. الوكيل يفكر بصوت مسموع، يختار أداة، ينفذها، ويلاحظ الناتج — حتى يصل للإجابة النهائية.

pip install langchain langchain-openai tavily-python from langchain_openai import ChatOpenAI from langchain_community.tools import TavilySearchResults from langchain.agents import create_react_agent, AgentExecutor from langchain_core.prompts import PromptTemplate llm = ChatOpenAI(model="gpt-4o-mini") tools = [TavilySearchResults(max_results=3)] from langchain_core.prompts import hub prompt = hub.pull("hwchase17/react") # قالب ReAct الجاهز agent = create_react_agent(llm, tools, prompt) executor = AgentExecutor(agent=agent, tools=tools, max_iterations=5) result = executor.invoke({"input": "ما آخر أخبار الذكاء الاصطناعي؟"}) print(result["output"])
⚠️ الأمان: الوكيل ينفذ أدوات حقيقية. لا تعطه أدوات حذف/كتابة على بيانات مهمة بدون صلاحيات محكمة، وحدد max_iterations ليمنع الدوران اللانهائي.

2. أنماط تعدد الوكلاء (Multi-Agent)

مهمة معقدة = عدة وكلاء متخصصون يتعاونون. أربعة أنماط مشهورة:

  • Supervisor: وكيل رئيسي يقرر أي وكيل متخصص ينفذ المهمة
  • Swarm: وكلاء متساوون يتعاونون، ويمكن للوكيل تمرير التحكم لغيره
  • Pipeline: تسلسل خطي — مخرجات الأول مدخلات الثاني (بحث ← تحليل ← تلخيص)
  • Hierarchy: هيكل هرمي (رئيسي ← ثانوي ← متخصصون)
متى تختار أي نمط؟ مهمة تحتاج تخصصات مختلفة → Supervisor. مهمة واحدة كبيرة تقسم → Swarm. خطوات متسلسلة ثابتة → Pipeline. مؤسسة متكاملة → Hierarchy. ابدأ دائماً بالأبسط ثم عقد.

3. وكيل تحليل البيانات (Data Analyst Agent)

مشروع عملي من السنة الأولى: وكيل يقرأ ملف CSV، يحلله إحصائياً، ويرسم رسوماً بيانية، ثم يكتب تقريراً بالعربية. نبنيه بأدوات: قراءة، تحليل، تصوير، تقرير.

pip install pandas ydata-profiling matplotlib plotly scipy import pandas as pd from langchain.tools import tool # 1) أداة: تحميل واستكشاف @tool def load_and_profile(path: str) -> str: """يحمّل ملف CSV ويُرجع أسماء الأعمدة، الأنواع، والقيم المفقودة.""" df = pd.read_csv(path) return (f"أعمدة: {list(df.columns)}\n" f"أنواع:\n{df.dtypes.to_string()}\n" f"مفقود:\n{df.isnull().sum().to_string()}") # 2) أداة: تحليل إحصائي @tool def describe_data(path: str) -> str: """يُرجع ملخصاً إحصائياً (mean, std, min, max) للأعمدة الرقمية.""" df = pd.read_csv(path) return df.describe().to_string() # 3) أداة: رسم بياني @tool def make_plot(path: str, column: str) -> str: """يرسم توزيع عمود ويحفظ صورة PNG، يعيد اسم الملف.""" df = pd.read_csv(path) df[column].hist() import matplotlib.pyplot as plt plt.savefig("chart.png") return "chart.png" # 4) تجميعها في وكيل from langchain.agents import create_react_agent, AgentExecutor agent_tools = [load_and_profile, describe_data, make_plot] agent = create_react_agent(llm, agent_tools, hub.pull("hwchase17/react")) executor = AgentExecutor(agent=agent, tools=agent_tools) print(executor.invoke({"input": "حمّل sales.csv وحلل المبيعات وارسم توزيعها"}))

4. الذاكرة طويلة المدى

الوكيل المثالي يتذكر عبر الجلسات. الطريقة العملية: تخزين ملخصات المحادثات أو المعرفة في قاعدة متجهات (Qdrant) واسترجاعها عند الحاجة — بدل إعادة إدخال كل شيء في كل مرة.

# أداة تخزين معرفة في Qdrant from qdrant_client import QdrantClient from qdrant_client.models import VectorParams, Distance, PointStruct client = QdrantClient("localhost", port=6333) client.create_collection( collection_name="memory", vectors_config=VectorParams(size=384, distance=Distance.COSINE), ) # عند نهاية جلسة: تلخيص وحفظ. عند سؤال جديد: استرجاع الملخصات ذات الصلة. client.upsert(collection_name="memory", points=[ PointStruct(id=1, vector=embed("المستخدم يفضّل التقارير المختصرة"), payload={"text": "المستخدم يفضّل التقارير المختصرة"}), ])

5. التمارين

تمرين 1: وكيل بحث
ابنِ وكيلاً بـ 3 أدوات: بحث ويب، حاسبة، ومحول عملات — وجرّبه على مهمة مركّبة.
تمرين 2: وكيل تحليل بيانات
امنح الوكيل ملف CSV حقيقياً واطلب منه: تنظيف، تحليل إحصائي، رسم، وتقريراً بالعربية.
تمرين 3: تعدد وكلاء
نفّذ نمط Supervisor: مدير يوزع الأسئلة بين وكيل تقني ووكيل أدبي.

📝 ملخص الوكلاء

  • Agent = نموذج + أدوات + حلقة قرار (ReAct)
  • Multi-Agent: Supervisor, Swarm, Pipeline, Hierarchy
  • Data Analyst Agent: أدوات قراءة وتحليل وتصوير
  • الذاكرة طويلة المدى: Qdrant لتخزين واسترجاع المعرفة
  • القيود: max_iterations + صلاحيات محكمة للأدوات
