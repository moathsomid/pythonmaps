RAG — التوليد المعزز بالاسترجاع

Retrieval Augmented Generation — بناء أنظمة إجابة تعتمد على بياناتك الخاصة

← العودة إلى الرئيسية

RAG (Retrieval-Augmented Generation) هو أشهر Pattern في الذكاء الاصطناعي التطبيقي 2024-2026. الفكرة بسيطة: قبل أن يولد نموذج اللغة (LLM) الإجابة، نسترجي له مقاطع ذات صلة من قاعدة معرفة خاصة بنا، ونضعها في سياق السؤال. بهذا يجاوب النموذج بناءً على بياناتك أنت، وليس على تدريبه العام فقط.

لماذا RAG؟ النموذج العام لا يعرف بياناتك السرية أو منتجاتك أو مستندات شركتك. RAG يحل ثلاث مشاكل: حداثة المعلومات، الخصوصية، وتقليل الهلاوس (Hallucination) لأن النموذج يرد اعتماداً على نصوص فعلية.

1. معمارية RAG الأساسية

أي نظام RAG له مرحلتان كبيرتان: مرحلة الإدخال (Ingestion) التي تُبنى مرة واحدة، ومرحلة الاستعلام (Query) التي تحدث في كل سؤال.

  • التقسيم Chunking: تقسيم المستندات إلى أجزاء صغيرة (chunks)
  • التضمين Embedding: تحويل كل جزء إلى متجه (vector)
  • التخزين Storage: حفظ المتجهات في قاعدة بيانات متجهات (Vector DB)
  • الاسترجاع Retrieval: عند السؤال، تحويله لمتجه وبحث الأقرب
  • التوليد Generation: تمرير السؤال + الأجزاء المسترجعة للنموذج
# تثبيت المكتبات pip install langchain langchain-openai langchain-community chromadb sentence-transformers

2. تقسيم المستندات (Chunking)

جودة التقسيم تحدد جودة الاسترجاع. جزء صغير جداً يفوّت السياق، وجزء كبير جداً يجلب معلومات لا علاقة لها بالسؤال. القاعدة الذهبية: جرب أحجاماً مختلفة (256، 512، 1024) وقس النتيجة.

# RecursiveCharacterTextSplitter — الأكثر استخداماً from langchain_text_splitters import RecursiveCharacterTextSplitter text = open('report.txt').read() splitter = RecursiveCharacterTextSplitter( chunk_size=512, chunk_overlap=50, # تداخل بين الأجزاء للحفاظ على السياق separators=["\n\n", "\n", ". ", " "], ) chunks = splitter.split_text(text) print(f"عدد الأجزاء: {len(chunks)}")
💡 متى تختار أي حجم؟ مستندات فنية طويلة → 1024. أسئلة وأجوبة قصيرة → 256. استخدم overlap حوالي 10-20% من الحجم لضمان عدم قطع المعنى عند الحدود.

3. التضمين والاسترجاع (Embedding + Retrieval)

نحول كل جزء إلى متجه باستخدام نموذج تضمين، ونخزنه في قاعدة بيانات متجهات. عند السؤال، نبحث عن المتجهات الأقرب تشابهاً (cosine similarity).

from langchain_community.embeddings import HuggingFaceEmbeddings from langchain_community.vectorstores import Chroma embeddings = HuggingFaceEmbeddings(model_name="sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2") # بناء المتجر وتخزين الأجزاء vectorstore = Chroma.from_texts(chunks, embedding=embeddings) # الاستعلام question = "ما هي أهداف المبيعات للربع الثالث؟" results = vectorstore.similarity_search(question, k=4) # أفضل 4 أجزاء for i, r in enumerate(results): print(f"--- النتيجة {i+1} ---") print(r.page_content[:200])
🔍 كيف يعمل؟ نموذج التضمين يحول النص إلى متجه رقمي بحيث تتقارب المتجهات ذات المعنى المتشابه. cosine similarity يقيس الزاوية بين المتجهين — القيمة الأقرب إلى 1 تعني تشابهاً أكبر. k=4 يعني أننا نسترجي أفضل 4 أجزاء فقط — الأجزاء الأقرب سؤالاً.

4. توليد الإجابة (Generation)

نمرر السؤال مع الأجزاء المسترجعة كنص سياق للنموذج، ونطلب منه الإجابة بناءً على هذا السياق فقط — دون معلومات خارجية.

from langchain_openai import ChatOpenAI from langchain_core.prompts import ChatPromptTemplate llm = ChatOpenAI(model="gpt-4o-mini") prompt = ChatPromptTemplate.from_messages([ ("system", """أجب بالعربية بناءً على السياق التالي فقط. إذا لم تجد الإجابة في السياق، قل: "لا أستطيع الإجابة من البيانات المتاحة". لا تخترع معلومات خارج السياق. السياق: {context}"""), ("human", "{question}"), ]) # دمج الأجزاء المسترجعة في نص سياق واحد context = "\n\n".join(r.page_content for r in results) response = llm.invoke(prompt.format(context=context, question=question)) print(response.content)
⚠️ مهم: بدون تعليمات "أجب من السياق فقط" سيجيب النموذج من معرفته العامة وقد يهلوس. حدد دائماً سلوك النموذج عندما لا يجد الإجابة.

5. تحسين الاسترجاع — Hybrid Search + Reranking

البحث المتجه وحده قد يفشل مع الأرقام والأسماء الدقيقة. الحل هو البحث الهجين: دمج البحث المتجه (المعنى) مع البحث النصي (الكلمات الدقيقة) باستخدام BM25، ثم إعادة الترتيب بنموذج cross-encoder يقيّم الأزواج (سؤال، جزء) بدقة أعلى.

from rank_bm25 import BM25Okapi from sentence_transformers import CrossEncoder # 1) النتائج المتجهة dense_results = vectorstore.similarity_search(question, k=10) # 2) النتائج النصية (BM25) tokenized = [chunk.split() for chunk in chunks] bm25 = BM25Okapi(tokenized) bm25_hits = bm25.get_top_n(question.split(), chunks, n=10) # 3) إعادة الترتيب بالـ cross-encoder على النتائج المدمجة reranker = CrossEncoder("cross-encoder/ms-marco-MiniLM-L-6-v2") candidates = list(dict.fromkeys(dense_results + bm25_hits)) pairs = [(question, c) for c in candidates] scores = reranker.predict(pairs) # ترتيب تنازلي حسب النتيجة ranked = [c for _, c in sorted(zip(scores, candidates), reverse=True)] top = ranked[:4]
💡 لماذا Reranking؟ البحث المتجه سريع لكنه تقريبي. الـ cross-encoder يقيّم كل زوج (سؤال، جزء) بدقة أعلى لكنه بطيء — لذلك نعيد ترتيب أفضل 10-20 نتيجة فقط، لا كل المكتبة. عادة يرفع الدقة 10-20%.

6. تقييم نظام RAG

كيف تعرف أن نظامك يعمل فعلاً؟ لا تكتفِ بالانطباع — استخدم مقاييس موضوعية. أشهر مكتبة: RAGAS.

  • Faithfulness: هل الإجابة مخلصة للسياق (لا هلاوس)؟
  • Answer Relevancy: هل الإجابة مناسبة للسؤال؟
  • Context Precision/Recall: هل الأجزاء المسترجعة دقيقة وكاملة؟
pip install ragas # مثال: تقييم مجموعة من الأسئلة مع الإجابات والسياقات المرجعية from datasets import Dataset from ragas import evaluate from ragas.metrics import faithfulness, answer_relevancy data = { "question": ["ما هي مبيعات الربع الثالث؟"], "answer": ["المبيعات بلغت 5 مليون ريال."], "contexts": [["حققت المبيعات 5 مليون ريال في الربع الثالث."]], "ground_truth": ["بلغت المبيعات 5 مليون ريال."], } ds = Dataset.from_dict(data) result = evaluate(ds, metrics=[faithfulness, answer_relevancy]) print(result)

تمرين 2: مقارنة chunk sizes
جرّب أحجام 256 و 512 و 1024 وقارن نتائج الاسترجاع على نفس الأسئلة.
تمرين 3: RAGAS
قيّم نظامك بـ RAGAS على 20 سؤالاً وسجّل faithfulness و answer_relevancy. حسّن حتى تصل لـ 85%+.
تمرين 4: Hybrid + Rerank
أضف BM25 و cross-encoder إلى نظامك وقارن الدقة قبل وبعد.

📝 ملخص RAG

  • RAG = استرجاع الأجزاء ذات الصلة + توليد الإجابة منها
  • Chunking: قسّم المستندات بحجم 256-1024 مع overlap
  • Embeddings: تحويل النص لمتجه، والبحث بالـ cosine similarity
  • Hybrid search: دمج البحث المتجه مع النصي (BM25)
  • Reranking: cross-encoder يحسّن الترتيب 10-20%
  • Evaluation: RAGAS يقيس faithfulness و relevancy
