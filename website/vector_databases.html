Vector Databases — قواعد بيانات المتجهات مع Qdrant

تخزين وبحث المتجهات بسرعة — العمود الفقري لأي نظام RAG

← العودة إلى الرئيسية

قواعد بيانات المتجهات صُممت لمشكلة واحدة: البحث عن المتشابه وليس المتطابق. بدلاً من مطابقة الأرقام والنصوص حرفياً، تقارن المتجهات بمعناها. هذه هي الآلية التي تجعل أنظمة RAG تبحث في ملايين المستندات خلال أجزاء من الثانية.

لماذا Qdrant؟ مفتوحة المصدر، سريعة، تدعم التصفية (Payload filtering) بقوة، وتدعم البحث الهجين (متجه + نص) في نفس القاعدة. تتوفر سحابية مجاناً للتجربة.

1. التضمين (Embeddings) باختصار

قبل أي قاعدة متجهات، تحتاج نموذج تضمين يحول النص إلى مصفوفة أرقام. المتجهات القريبة معنوياً تكون قريبة عددياً — هذا هو أساس كل شيء.

pip install qdrant-client sentence-transformers from sentence_transformers import SentenceTransformer model = SentenceTransformer("sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2") vec = model.encode("ما هو الذكاء الاصطناعي؟") print(vec.shape) # (384,) — متجه من 384 رقم
💡 تنويه: قرّب (Normalize) المتجهات قبل التخزين إذا كنت ستقيس بالـ cosine — أو أعلنها لـ Qdrant وسيحسبها لك. إعادة استخدام نفس نموذج التضمين عند البحث إلزامية، وإلا فستقارن أرقاماً لا معنى لها.

2. تشغيل Qdrant

أسهل طريقة للتجربة محلياً: عبر Docker. كل الأوامر بعدها تعمل بنفس الطريقة على السحابة.

# تشغيل Qdrant عبر Docker docker run -p 6333:6333 -p 6334:6334 -v $(pwd)/qdrant_storage:/qdrant/storage qdrant/qdrant # الواجهة: http://localhost:6333 | الـ Dashboard: http://localhost:6333/dashboard

3. إنشاء Collection وإضافة نقاط

الـ Collection تشبه الجدول في قاعدة البيانات العادية، والـ Point تشبه الصف — كل نقطة تحمل متجهاً وبايلود (بيانات وصفية) اختيارياً.

from qdrant_client import QdrantClient from qdrant_client.models import VectorParams, Distance, PointStruct client = QdrantClient("localhost", port=6333) # إنشاء مجموعة client.create_collection( collection_name="documents", vectors_config=VectorParams(size=384, distance=Distance.COSINE), ) # إضافة نقاط (متجه + بايلود) points = [ PointStruct(id=1, vector=model.encode("البحث عن المعلومات ضروري"), payload={"title": "مقدمة", "author": "سارة"}), PointStruct(id=2, vector=model.encode("قواعد المتجهات تسرع البحث"), payload={"title": "Qdrant", "author": "أحمد"}), ] client.upsert(collection_name="documents", points=points)
🔍 كيف يعمل؟ Distance.COSINE يقيس التشابه بالزاوية بين المتجهات — الأكثر شيوعاً للنصوص. البايلود (payload) هو بيانات وصفية تُحفظ مع كل نقطة (عنوان، مؤلف، تاريخ...) وتُستخدم لاحقاً للتصفية.

4. البحث والتصفية

القوة الحقيقية في Qdrant: دمج البحث المتجه مع التصفية على البايلود في استعلام واحد سريع.

# بحث بسيط hits = client.search( collection_name="documents", query_vector=model.encode("أسرع طريقة للبحث"), limit=3, ) # بحث مع تصفية على البايلود hits = client.query_points( collection_name="documents", query=model.encode("البحث"), query_filter=Filter( must=[FieldCondition(key="author", match=MatchValue(value="أحمد"))] ), limit=5, ).points for hit in hits: print(hit.payload, hit.score)

5. الفهارس وضبط الأداء

للتعامل مع ملايين المتجهات، تعتمد Qdrant على خوارزمية HNSW التي تضحي بقليل من الدقة مقابل سرعة هائلة. كما يجب إنشاء فهارس على حقول البايلود التي تصفّي بها كثيراً.

# HNSW هو الفهرس الافتراضي — يمكنك ضبط معاملاته عند الإنشاء client.create_collection( collection_name="big", vectors_config=VectorParams(size=384, distance=Distance.COSINE), hnsw_config=HnswConfigDiff( m=16, # روابط كل عقدة — أعلى = أدق وأبطأ ef_construct=100, # جودة البناء ), ) # فهرس بايلود للتصفية السريعة client.create_payload_index( collection_name="documents", field_name="author", field_schema=PayloadSchemaType.KEYWORD, )
⚠️ أداء: ef_construct أعلى = بناء أدق لكنه أبطأ. ضع فهرساً على كل حقل بايلود تصفّي به كثيراً، وإلا سيمسح Qdrant كل النقاط للتصفية (مسح كامل).

6. FAISS مقابل Qdrant

كثيراً ما يسأل المبتدئون: ما الفرق؟ كلاهما يبحث في المتجهات، لكن السياق مختلف.

  • FAISS: مكتبة من Facebook — داخل ذاكرة جهازك، ممتازة للنماذج والبحث السريع في ذاكرة محدودة، بلا خادم
  • Qdrant: قاعدة بيانات كاملة — خادم، تخزين دائم، تصفية بايلود، تعدد مستخدمين، وتدعم البحث الهجين
  • القاعدة: للتطبيق المنتج والمشاركة بين مستخدمين → Qdrant. للتجارب المحلية والنماذج → FAISS

📝 ملخص Vector Databases

  • Qdrant: قاعدة بيانات متجهات مفتوحة المصدر سريعة
  • Collection/Point: الجدول/الصف في قاعدة المتجهات
  • Payload: بيانات وصفية تُستخدم للتصفية أثناء البحث
  • HNSW: الفهرس الافتراضي — مقايضة سرعة مقابل دقة
  • الاستخدام: Qdrant للتطبيقات المنتجة، FAISS للتجارب المحلية
