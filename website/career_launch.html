الأسابيع 101-104: السيرة النهائية، التقديم على الوظائف، والعمل الحر

← العودة إلى الرئيسية

الآن بعد كل هذا — حان وقت الانطلاق: سيرة نهائية، تقديم ذكي، عمل حر، وخطة مستقبلية واقعية.

1. السيرة الذاتية النهائية

  • صفحة واحدة (إلا لخبرة 10+ سنوات)
  • النتائج بالأرقام: "رفعت دقة RAG من 70% إلى 88%"
  • قسم مشاريع: 3-4 مشاريع باسم + رابط + تقنيات
  • لا صور/ألوان مبالغ فيها — نظيف وقابل للقراءة آلياً (ATS)
  • صيغة PDF دائماً
# قالب بسيط لوصف مشروع في السيرة # AI Platform — رابط # منصة أسئلة على مستنداتك: FastAPI + Qdrant + Docker + CI/CD # · رفع دقة الإجابات إلى 88% عبر hybrid search + reranking # · نشر آلي عبر GitHub Actions إلى AWS EC2

2. التقديم على الوظائف

  • جهّز 3 نسخ من السيرة حسب الدور (AI Engineer / Backend / Data)
  • استهدف 10-15 شركة جيداً بدل 100 إرسال عشوائي
  • خصص رسالة تعريفية لكل شركة (2-3 جمل عن مشروعك المشابه لعملهم)
  • تابع بعد أسبوع برسالة مهذبة

3. منصات العمل الحر (Freelance)

العمل الحر يعطيك خبرة حقيقية ودخلاً مبكراً ومرجعيات (reviews).

  • منصات: Upwork، Freelancer، مستقل، بعيد — ابدأ بأسعار أقل لبناء التقييمات
  • أول مشاريعك: روبوت دردشة، موقع معرفي، رفع مستندات — مشاريع صغيرة سريعة
  • التسليم: مشروع Dockerized + README + demo فيديو قصير
المنصةالنوعأفضل لـالسعر التقريبي للبداية
Upworkعالمية (بالدولار)مشاريع AI/Backend طويلة20-40$ / ساعة
Freelancerعالمية (بالدولار)مشاريع صغيرة وسريعة15-30$ / ساعة

بعيدعربيةوظائف Freelance عربية8-20$ / ساعة
Khamsat / خمساتعربيةمهام صغيرة جاهزة التسليممن 10$ لكل خدمة
💡 نصيحة: ابدأ على منصة واحدة فقط (يفضّل Upwork أو مستقل)، أنجز 3-5 مشاريع صغيرة بسرعة وبسعر أقل، اجمع تقييمات 5 نجوم، ثم ارفع أسعارك تدريجياً. التقييمات الجيدة تجلب العملاء، لا العكس.

4. تحديد السعر

# معادلة بداية بسيطة # سعر الساعة = (راتب_مطلوب_شهرياً) / 160 × 1.3 (ضرائب+فجوات) # أو: # التسعير حسب المشروع = تقدير الساعات × السعر + 20% طوارئ # مثال: تريد 4000$ شهرياً # 4000 / 160 = 25$ / ساعة → ابدأ بـ 20-30$

5. المراجعة النهائية والتخطيط

  • راجع الـ 104 أسبوعاً: ما الذي أتقنته فعلاً؟ سجّله
  • خطة 90 يوماً قادمة: هدف واحد واضح (وظيفة/عميل/مشروع)
  • استمر بالتعلم: الـ AI يتغير أسبوعياً — راجع أخباره دورياً

6. التمارين

تمرين 1: سيرة نهائية
اكتب سيرتك النهائية بمعايير هذا الدرس وشاركها مع 2-3 أشخاص للمراجعة.
تمرين 2: أول عرض Freelance
ابحث عن مشروع صغير على منصة عمل حر وقدّم عرضاً مخصصاً مع معاينة سريعة لمهاراتك.

📝 خطتك بعد الخطة

  • سيرة نهائية + ملف LinkedIn + GitHub مصقول
  • 10-15 تقديماً مستهدفاً أسبوعياً
  • مشروع Freelance واحد على الأقل
  • هدف 90 يوماً واضح + مراجعة أسبوعية
