Security + Performance

الأسابيع 85-88: تحصين النظام وتحسين الأداء واختبار التحمل

← العودة إلى الرئيسية

قبل الإنتاج، راجع نظامك بعين المهاجم ثم بعين مهندس الأداء. هذان الجانبان هما ما يفصل تطبيقاً هاوياً عن تطبيق احترافي.

1. تحصين الأمان (Security Hardening)

  • مصادقة صحيحة: OAuth2/JWT بصلاحيات أدنى (least privilege)
  • Rate Limiting: حدد طلبات المستخدم الواحد لمنع الهجمات
  • إخفاء الأسرار: لا أسرار في الكود أو git — استخدم env/Secrets Manager
  • HTTPS إجباري + HSTS + CSRF للحماية
  • تحديث التبعيات: راقب CVE وحافظ على `pip audit`

2. Rate Limiting

from slowapi import Limiter, _rate_limit_exceeded_handler from slowapi.util import get_remote_address limiter = Limiter(key_func=get_remote_address) @app.get("/chat") @limiter.limit("20/minute") # 20 طلباً في الدقيقة def chat(request: Request): return answer(request.query_params["q"])

3. تحسين الأداء

  • Cache: Redis لتكرار الاستعلامات والاستجابات الشائعة
  • تجميع الحمولة: pagination و limit على كل القوائم
  • Indexes: على كل عمود استعلامات متكررة (بعد EXPLAIN ANALYZE)
  • N+1: استخدم eager loading في SQLAlchemy
  • Async: لعمليات I/O المتزامنة

4. اختبار التحمل (Load Testing)

# locustfile.py from locust import HttpUser, task, between class User(HttpUser): wait_time = between(0.5, 2) @task def get_status(self): self.client.get("/health") @task(3) def ask_question(self): self.client.post("/chat", json={"q": "ما هو الذكاء الاصطناعي؟"}) # locust -f locustfile.py --host http://localhost:8000
💡 اقرأ النتائج: راقب p95 و p99 لا المتوسط فقط. تحمل النظام = عدد المستخدمين × متوسط الطلبات × زمن الاستجابة المطلوب.

5. Chaos Engineering

اختبر مرونة نظامك بتعطيل أجزاء منه عمداً في بيئة اختبار: اقتل قاعدة البيانات، أوقف Redis، أعد تشغيل عشوائياً — وتأكد أن النظام يتعافى.

# مثال: اختبر ماذا يحدث لو توقف Redis docker stop redis # نتوقع: يعمل النظام جزئياً (fallback بدون cache) مع تنبيه docker start redis # يتعافى تلقائياً

6. التمارين

تمرين 1: تدقيق أمان
راجع مشروعك: أضف rate limit، غيّر كل الأسرار، وفعّل HTTPS.
تمرين 2: تحميل 500 مستخدم
حمّل نظامك بـ 500 مستخدم متزامن وسجّل p95 قبل وبعد تحسين cache.
