LangChain — بناء تطبيقات LLM

الوحدات الجاهزة لربط النماذج بالبيانات والأدوات: Prompts, Chains, Memory, Agents

← العودة إلى الرئيسية

LangChain إطار عمل يجمع كل ما تحتاجه لتطبيق LLM في وحدات جاهزة: قوالب للرسائل (Prompts)، سلاسل من الخطوات (Chains)، ذاكرة للمحادثة (Memory)، وأدوات للوكيل (Tools). بدلاً من كتابة كل شيء يدوياً، تستخدم مكوناته الموثوقة.

💡 نصيحة: افهم المكونات أولاً ثم استخدم الواجهات عالية المستوى. لا تعتمد على الـ default prompt — اكتب رسائل مخصصة لمشكلتك دائماً.

1. قوالب الرسائل (Prompt Templates)

بدلاً من بناء الرسائل نصياً (عرضة للأخطاء)، استخدم قوالب تُملأ بالمتغيرات تلقائياً.

pip install langchain langchain-openai from langchain_core.prompts import ChatPromptTemplate from langchain_openai import ChatOpenAI llm = ChatOpenAI(model="gpt-4o-mini") prompt = ChatPromptTemplate.from_messages([ ("system", "أنت خبير مبيعات تجيب بأسلوب ودّي."), ("human", "لخّص إنجازات {name} خلال {period}"), ]) # ملء القالب واستدعاء النموذج response = prompt.format_messages(name="أحمد", period="الربع الأخير") print(llm.invoke(response).content)

2. السلاسل (Chains)

الـ Chain تربط خطوات متعددة معاً — مخرجات الخطوة الأولى تصبح مدخلات الثانية. استخدم RunnableSequence (أو LCEL) للربط الأنيق.

from langchain_core.output_parsers import StrOutputParser # سلسلة: نص ← تلخيص ← ترجمة summarize = prompt | llm | StrOutputParser() summary = summarize.invoke({"name": "المنتج", "period": "السنة"}) print(summary)
🔍 رمز | : في LangChain (LCEL) الرمز | يربط المكونات مثل أنابيب Linux — كل مكوّن يستقبل ناتج الذي قبله. هذه هي الطريقة الحديثة لبناء السلاسل.

3. تحليل المخرجات (Output Parsers)

غالباً تريد النموذج يعيد JSON منظماً لا نصاً حراً. الـ output parser يضمن أن المخرجات صالحة ويفحصها على مخطط (schema).

from langchain_core.output_parsers import JsonOutputParser from langchain_core.pydantic_v1 import BaseModel, Field class SalesReport(BaseModel): total: float = Field(description="إجمالي المبيعات") growth: str = Field(description="نسبة النمو") parser = JsonOutputParser(pydantic_object=SalesReport) prompt_with_schema = ChatPromptTemplate.from_messages([ ("system", "استخرج المعلومات وأعدها كـ JSON. {format_instructions}"), ("human", "{input}"), ]).partial(format_instructions=parser.get_format_instructions()) chain = prompt_with_schema | llm | parser data = chain.invoke({"input": "مبيعاتنا 5 مليون ونسبة النمو 12%"}) print(data) # {"total": 5000000.0, "growth": "12%"}

4. الذاكرة (Memory)

النموذج بلا حالة — لا يتذكر الجولة السابقة. الذاكرة تحفظ المحادثة وتمررها مع كل سؤال. للجلسات الطويلة، الذاكرة الملخصة (SummaryMemory) توفر الرموز (tokens).

from langchain.memory import ConversationSummaryMemory from langchain.chains import ConversationChain memory = ConversationSummaryMemory(llm=llm, max_token_limit=200) chain = ConversationChain(llm=llm, memory=memory) print(chain.predict(input="اسمي أحمد وأعمل مهندس ذكاء اصطناعي")) print(chain.predict(input="ما اسمي؟")) # يتذكر!
⚠️ الذاكرة: الذاكرة الكاملة (Buffer) تملأ سياقك بسرعة في المحادثات الطويلة — كلفتها باهظة. الملخصة (Summary) تخزن خلاصة دورية وتوفر مساحة كبيرة.

5. الوكيل مع الأدوات (Agents + Tools)

الوكيل (Agent) لا يجيب فقط — يقرر ما الأداة التي سيستخدمها لتنفيذ مهمة (بحث، حساب، استدعاء API...). تُعرّف الأدوات بدالة بايثون + وصف واضح.

from langchain.tools import tool from langchain.agents import create_react_agent, AgentExecutor from langchain_core.prompts import PromptTemplate # 1) تعريف أداة @tool def convert_usd_to_riyal(amount: float) -> float: """يحول مبلغاً من الدولار إلى ريال سعودي.""" return amount * 3.75 # 2) إنشاء الوكيل agent_prompt = PromptTemplate.from_template( "أجب بأدواتك. {tools}\n{input}\n{agent_scratchpad}" ) agent = create_react_agent(llm, [convert_usd_to_riyal], agent_prompt) executor = AgentExecutor(agent=agent, tools=[convert_usd_to_riyal]) print(executor.invoke({"input": "كم يساوي 100 دولار بالريال؟"}))
💡 وصف الأداة مهم جداً: النموذج يقرر الأداة بناءً على وصفها. وصف واضح = قرار صحيح. أجبر الوكيل على حدود: max_iterations و early_stopping_method لمنع الحلقات اللانهائية.

6. التمارين

تمرين 1: سلسلة ترجمة
ابنِ سلسلة: إدخال نص ← ترجمة إلى الإنجليزية ← تلخيص ← إخراج JSON.
تمرين 2: محادثة بذاكرة
أنشئ روبوت مساعد تذكّر تفضيلات المستخدم بين الجلسات باستخدام SummaryMemory.
تمرين 3: وكيل بأدوات
عرّف 3 أدوات (بحث، حساب، تحويل عملات) وابنِ وكيلاً يستخدمها بذكاء.

📝 ملخص LangChain

  • Prompt Templates: قوالب رسائل تُملأ بالمتغيرات
  • Chains (LCEL): ربط الخطوات بالرمز |
  • Output Parsers: مخرجات JSON منظمة وموثوقة
  • Memory: Buffer للقصيرة، Summary للطويلة
  • Agents + Tools: وكيل يقرر ويستخدم أدواتك
