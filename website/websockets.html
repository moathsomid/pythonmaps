WebSockets بعمق

الأسبوع 61: اتصال ثنائي الاتجاه في الزمن الحقيقي — chat، إشعارات، بث مباشر

← العودة إلى الرئيسية

WebSockets يفتح قناة اتصال مستمرة ثنائية الاتجاه بين المتصفح والخادم. خلافاً لـ HTTP (طلب/استجابة)، الاثنان يتبادلان الرسائل بحرية في أي لحظة.

1. HTTP vs WebSocket

  • HTTP: تطلب ثم يستجيب ثم يُغلق الاتصال — جيد للـ APIs العادية
  • WebSocket: قناة مفتوحة دائماً — جيد للـ chat والإشعارات والبث الحي

2. الخادم مع FastAPI

from fastapi import FastAPI, WebSocket, WebSocketDisconnect from typing import list app = FastAPI() connections: list[WebSocket] = [] @app.websocket("/ws") async def websocket_endpoint(websocket: WebSocket): await websocket.accept() connections.append(websocket) try: while True: data = await websocket.receive_text() # بث الرسالة لكل المتصلين for conn in connections: await conn.send_text(f"user: {data}") except WebSocketDisconnect: connections.remove(websocket)
💡 البث لجميع المتصلين هو أساس أنظمة chat والـ room. كل رسالة تصل لأي متصل تنعكس على الجميع فوراً.

3. العميل (JavaScript)

// الاتصال بالخادم const ws = new WebSocket("ws://localhost:8000/ws"); ws.onopen = () => console.log("متصل"); ws.onmessage = (e) => document.getElementById("chat").innerHTML += `<p>${e.data}</p>`}; function send() { const msg = document.getElementById("msg").value; ws.send(msg); }

4. إشعارات فورية + توثيق JWT

تُستخدم WebSockets في لوحات التحكم لإرسال إشعار فوري عند حدوث حدث (طلب جديد، تنبيه، خطأ). يمكن ربط الاتصال بمستخدم عبر JWT في الـ query string.

# استقبال token في الاتصال @app.websocket("/ws/notify") async def notify(websocket: WebSocket, token: str): await websocket.accept() user = verify_token(token) # فك التوكن والتحقق await websocket.send_text(f"مرحباً {user} — أنت متصل بالإشعارات") while True: event = await event_queue.get() # أحداث من Celery/Redis await websocket.send_json(event)
⚠️ إدارة الاتصالات: مع عدد كبير من المستخدمين، احفظ الاتصالات في Redis Pub/Sub (عبر عملية واحدة) بدلاً من قائمة محلية، حتى تعمل التطبيقات متعددة العمالات (multiple workers).
