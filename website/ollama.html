Ollama — تشغيل النماذج محلياً

شغّل نماذج LLM على جهازك: خصوصية، مجانية، وبدون إنترنت

← العودة إلى الرئيسية

Ollama أداة تجعل تشغيل نماذج اللغة الكبيرة محلياً أمراً في غاية السهولة — أمر واحد لتشغيل أي نموذج مفتوح (Llama, Qwen, Mistral, Phi...). مميزات هذا النهج: بياناتك لا تغادر جهازك، لا تكاليف API، ويعمل حتى بدون إنترنت.

أين تبدأ؟ ابدأ بنموذج خفيف مثل llama3.2 (3B) أو phi3:mini — يعملان على أجهزة بلا GPU. جرّب النماذج العربية مثل qwen2.5 و jaal:7b للأداء العربي.

1. التثبيت وإدارة النماذج

# Linux curl -fsSL https://ollama.com/install.sh | sh # macOS / Windows: حمّل من الموقع الرسمي ollama.com # سحب وتشغيل نموذج (ينزّل عند أول تشغيل) ollama run llama3.2 # أوامر إدارة النماذج ollama pull qwen2.5 # تنزيل نموذج دون تشغيله ollama list # النماذج المحمّلة ollama rm llama3.2 # حذف نموذج ollama ps # النماذج العاملة حالياً
🔍 كيف يعمل؟ ollama run يفتح محادثة تفاعلية في الطرفية. النموذج يُحمَّل في الذاكرة عند أول استخدام ويبقى للطلبات التالية — لاحظ ollama ps لترى الذاكرة المستخدمة.

2. التكميم (Quantization) — GGUF

النماذج المفتوحة تُنشر بصيغة GGUF مع مستويات تكميم مختلفة. التكميم يقلص الأوزان (مثلاً من 16-bit إلى 4-bit) فيقل الحجم ويقل استهلاك الذاكرة — مقابل خسارة طفيفة في الجودة. الفائدة: نموذج 7B يعمل على 8GB RAM بفضل التكميم.

# الأسماء في Ollama تشمل مستوى التكميم: q4_0, q5_K_M, q8_0... ollama pull llama3.2:3b-q4_0 # ~2GB ollama pull llama3.2:3b-q8_0 # ~3.4GB — أدق لكن أثقل # القاعدة: q4 أو q5 متوازنة جيداً. q8 أدق للمهام الدقيقة.
⚠️ ملاحظة: التكميم الأقل لا يعني دائماً أداء أسوأ بكثير — لمعظم المهام q4_0 ممتاز. جرّب الأحجام وقارن الجودة على مهمتك الفعلية بدلاً من الافتراضات.

3. الدمج مع بايثون — API

Ollama يشغّل خادماً محلياً (localhost:11434) يتوافق مع صيغة OpenAI — يمكنك استخدام openai أو requests مباشرة.

# طريقة 1: مكتبة ollama pip install ollama import ollama response = ollama.chat( model="llama3.2", messages=[{"role": "user", "content": "اكتب جملة عن الذكاء الاصطناعي بالعربية"}], ) print(response["message"]["content"])
# طريقة 2: API متوافق مع OpenAI (streaming) from openai import OpenAI client = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama") stream = client.chat.completions.create( model="qwen2.5", messages=[{"role": "user", "content": "اشرح الـ RAG باختصار"}], stream=True, ) for chunk in stream: print(chunk.choices[0].delta.content or "", end="")
💡 تدفق (Streaming): بهذه الطريقة تظهر الكلمات فور توليدها بدل انتظار الإجابة كاملة — تجربة المستخدم أفضل بكثير في تطبيقات الدردشة.

4. النماذج العربية

بعض النماذج مدربة على العربية بشكل أفضل. للبحث عن نماذج عربية في Ollama استخدم المكتبة الرسمية.

ollama pull qwen2.5:7b # قوي في العربية ollama pull jaal:7b # نموذج عربي مخصص ollama pull arablama:7b # عربي

5. LoRA — ضبط دقيق خفيف

لو احتجت نموذجاً يفهم بياناتك الخاصة، LoRA (Low-Rank Adaptation) هو أخف طرق الضبط الدقيق: يدرّب طبقات صغيرة إضافية بدل كل الأوزان — أسرع وأرخص بكثير. يمكن إنشاء Modelfile لإضافة ضبط على نموذج Ollama.

# Modelfile — إنشاء نسخة معدلة من نموذج # من الأساس: llama3.2 SYSTEM """[المساعد] أنت خبير تسويق عربي. أجب دائماً بالعربية الفصحى.""" PARAMETER temperature 0.7 PARAMETER num_ctx 4096 # البناء والاستخدام ollama create my-marketing-assistant -f Modelfile ollama run my-marketing-assistant

6. التمارين

تمرين 1: تشغيل النموذج
شغّل llama3.2 محلياً واطرح عليه 5 أسئلة بالعربية وقيّم جودة الإجابات.
تمرين 2: مقارنة التكميم
قارن إجابات q4_0 و q8_0 على نفس السؤال ولاحظ فرق الجودة والحجم.
تمرين 3: تطبيق دردشة
ابنِ تطبيق دردشة بسيط بـ FastAPI + Ollama مع بث الإجابات (streaming).

📝 ملخص Ollama

  • Ollama: يشغّل نماذج LLM محلياً بسهولة تامة
  • GGUF / Quantization: تقليص النماذج لتعمل على أجهزة محدودة
  • API: متوافق مع OpenAI على localhost:11434
  • Streaming: بث الإجابات لتحسين التجربة
  • LoRA / Modelfile: تخصيص النموذج لمهمتك
