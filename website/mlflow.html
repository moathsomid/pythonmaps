MLflow — تتبع التجارب وإدارة النماذج

سجّل كل تجربة، قارن النتائج، وادفع النموذج الأفضل للإنتاج

← العودة إلى الرئيسية

عندما تدرّب نموذجاً، تريد أن تتذكر: أي المعاملات (hyperparameters) جرّبت؟ ما الدقة التي حصلت عليها؟ مع أي بيانات؟ MLflow هو المعيار العملي للإجابة عن هذه الأسئلة — يسجل كل تجربة (run) بمعاملاتها ومقاييسها وملفاتها، ويعرضها في واجهة مقارنة.

لماذا يهم؟ بدون تتبع منهجي، ستعيد تدريب النموذج وتنسى إعداداتك، ولن تعرف أي تجربة كانت الأفضل. MLflow يجعل كل تجربة قابلة للمقارنة وإعادة الإنتاج.

1. التتبع (Tracking) الأساسي

المفاهيم: Experiment (مشروع)، Run (تجربة واحدة)، Parameters (المدخلات)، Metrics (النتائج)، Artifacts (الملفات مثل النموذج نفسه).

pip install mlflow scikit-learn import mlflow from sklearn.ensemble import RandomForestClassifier from sklearn.datasets import load_iris from sklearn.model_selection import train_test_split from sklearn.metrics import accuracy_score mlflow.set_experiment("iris-classifier") with mlflow.start_run(run_name="rf-n100-d5"): # تسجيل المعاملات mlflow.log_param("n_estimators", 100) mlflow.log_param("max_depth", 5) # التدريب X, y = load_iris(return_X_y=True) X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3) model = RandomForestClassifier(n_estimators=100, max_depth=5) model.fit(X_tr, y_tr) acc = accuracy_score(y_te, model.predict(X_te)) # تسجيل المقاييس والملفات mlflow.log_metric("accuracy", acc) mlflow.log_artifact("model.joblib")
# تشغيل الواجهة الرسومية mlflow ui --port 5000 # افتح http://localhost:5000 — قارن التجارب، المنحنيات، والملفات

2. المقارنة بين التجارب

درّب عدة نماذج بنفس الكود مع معاملات مختلفة، ثم استخدم الواجهة لمقارنة دقتها. برمجياً يمكنك استرجاع النتائج لاختيار الأفضل تلقائياً.

from mlflow.tracking import MlflowClient client = MlflowClient() exp = client.get_experiment_by_name("iris-classifier") # استرجاع كل التجارب مع مقاييسها runs = client.search_runs(exp.experiment_id, order_by=["metrics.accuracy DESC"]) for run in runs: print(run.info.run_id, run.data.params, run.data.metrics["accuracy"])

3. التسجيل التلقائي (Auto-logging)

مع إطارات التدريب المعروفة، يسجل MLflow كل شيء تلقائياً — دون كتابة سطر تسجيل واحد.

mlflow.sklearn.autolog() mlflow.pytorch.autolog() # أو أي إطار # أي تدريب بعد الآن يُسجَّل تلقائياً: المعاملات، المقاييس، والنموذج with mlflow.start_run(): model = RandomForestClassifier(n_estimators=200) model.fit(X_tr, y_tr)

4. سجل النماذج (Model Registry)

الـ Registry ينظم دورة حياة النموذج: تسجيل نسخة، ترقيمها، ثم نقلها عبر المراحل: Staging (اختبار) ← Production (تشغيل) ← Archived (أرشيف).

# تسجيل النموذج من تجربة run_id = "your-run-id" model_uri = f"runs:/{run_id}/model" registered = mlflow.register_model(model_uri, name="IrisRF") # نقل النموذج للمرحلة client = MlflowClient() client.transition_model_version_stage( name="IrisRF", version=registered.version, stage="Production", )
⚠️ النقل للمراحل: لا تنقل نسخة إلى Production قبل اجتيازها تقييمك على بيانات الاختبار. استخدم aliases (مثل "champion") لتحديد النموذج الحالي بدل الأرقام.

5. تشغيل النموذج (Serving)

شغّل النموذج المسجل كـ API بأمر واحد — يحمّل MLflow النموذج ويهيئه.

# تشغيل الخدمة mlflow models serve -m "models:/IrisRF/Production" -p 5001 # الاستدعاء curl -X POST http://localhost:5001/invocations \ -H "Content-Type: application/json" \ -d '{"inputs": [[5.1, 3.5, 1.4, 0.2]]}'

📝 ملخص MLflow

  • Tracking: تجارب، معاملات، مقاييس، وملفات
  • Autolog: تسجيل تلقائي مع إطارات التدريب
  • Registry: نسخ النموذج ومراحله (Staging/Production)
  • Serving: تشغيل النموذج كـ API فوري
  • UI: مقارنة بصرية لكل التجارب
