الأسابيع 81-84: لوحة مراقبة مركزية لكل نظامك — مقاييس، إنذارات، أتمتة

← العودة إلى الرئيسية

المشروع: لوحة تحكم مركزية تعرض صحة كل نظامك في مكان واحد: الـ API، قاعدة البيانات، الـ RAG، الوكلاء، والخوادم — مع إنذارات تنبّهك فور حدوث مشكلة.

🎯 القياس: لوحة تعرض 10+ مؤشراً حياً، إنذارات عبر البريد/Telegram عند تجاوز الحدود، وسجل أحداث، منشورة على الإنترنت.

1. المؤشرات المراقبة

  • API: طلبات/ثانية، زمن استجابة p95، نسبة الأخطاء
  • Database: اتصالات نشطة، حجم، بطء الاستعلامات
  • RAG: زمن الاسترجاع، دقة الإجابات (RAGAS أسبوعياً)
  • Agents: مدة التنفيذ، نسبة النجاح، عدد الجولات
  • Infra: CPU، RAM، Disk لكل خادم

2. الواجهة الخلفية

# API للوحة: يجمع المقاييس من Prometheus from prometheus_api_client import PrometheusConnect prom = PrometheusConnect(url="http://prometheus:9090") @app.get("/metrics/summary") def summary(): return { "requests": prom.get_metric_range_data("http_requests_total"), "latency_p95": prom.get_metric_range_data("http_request_duration_seconds"), }

لوحة بسيطة بـ Chart.js أو أداة جاهزة مثل Grafana مدمجة. تُحدَّث تلقائياً كل 10 ثوانٍ.
