Observability — المراقبة والتتبع

الأسابيع 77-80: Prometheus، Grafana، Nginx، وتتبع الأنظمة الموزعة

← العودة إلى الرئيسية

لا يمكنك تحسين ما لا تراقبه. Observability تعني القدرة على فهم حالة نظامك من خارجها: مقاييس (Metrics)، سجلات (Logs)، وتتبعات (Traces).

1. المقاييس الأساسية

  • معدل الطلبات: كم طلب في الثانية؟
  • زمن الاستجابة: p50، p95، p99 (متوسط وأذناب)
  • معدل الأخطاء: نسبة 5xx و 4xx
  • الموارد: CPU، RAM، Disk

2. Prometheus + Grafana

Prometheus يجمع المقاييس، وGrafana يرسمها على لوحات جميلة.

# تعريض المقاييس في FastAPI (prometheus-fastapi-instrumentator) from prometheus_fastapi_instrumentator import Instrumentator from fastapi import FastAPI app = FastAPI() Instrumentator().instrument(app).expose(app) # الآن /metrics يعرض مقاييس Prometheus
# prometheus.yml — مصدر الجمع scrape_configs: - job_name: api metrics_path: /metrics static_configs: - targets: ['api:8000']
# سؤال Grafana: متوسط زمن الاستجابة (ms) rate(http_request_duration_seconds_sum[5m]) / rate(http_request_duration_seconds_count[5m]) * 1000

3. Nginx كـ Reverse Proxy

Nginx يتلقى الطلبات الخارجية ويوزعها على تطبيقك (أو عدة تطبيقات) مع SSL وإنهاء HTTPS.

server { listen 443 ssl; server_name app.example.com; ssl_certificate /etc/letsencrypt/live/app.example.com/fullchain.pem; ssl_certificate_key /etc/letsencrypt/live/app.example.com/privkey.pem; location / { proxy_pass http://127.0.0.1:8000; proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; } location /ws/ { proxy_pass http://127.0.0.1:8000; proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; # ضروري لـ WebSocket proxy_set_header Connection "upgrade"; } }

4. سجلات منظمة (Structured Logging)

import structlog structlog.configure(processors=[ structlog.processors.add_log_level, structlog.processors.StackInfoRenderer(), structlog.processors.JSONRenderer(), # سجلات JSON قابلة للبحث ]) logger = structlog.get_logger() logger.info("request_handled", path="/chat", status=200, duration_ms=312)

5. تتبع الأنظمة الموزعة (Distributed Tracing)

في نظام Multi-Agent الموزع، طلب واحد يمر بعدة خدمات. الـ Tracing يتتبع رحلة الطلب كاملة عبر جميعها (مع OpenTelemetry + Jaeger).

from opentelemetry import trace from opentelemetry.trace import get_tracer tracer = get_tracer("research") with tracer.start_as_current_span("search_web"): results = search(query) # يظهر في Jaeger كمدة زمنية
