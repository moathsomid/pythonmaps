مشروع Multi-Agent Research

الأسابيع 69-72: نظام بحث آلي متكامل بفريق وكلاء — بناء، اختبار، نشر

← العودة إلى الرئيسية

المشروع الختامي للقسم: نظام يبحث في موضوع معين عبر الويب، يحلل المصادر، يكتب تقريراً محكماً، ويسلّمه للمستخدم — كل ذلك بفريق وكلاء متعاونين، ومنشور للاستخدام الحقيقي.

🎯 القياس: نظام يعمل: أدخل موضوعاً → استلم تقريراً كاملاً خلال 2-3 دقائق مع استشهادات، ودقة محتوى عالية + واجهة API ونشر على الإنترنت.

1. المعمارية

  • Planner: يقسّم الموضوع لأسئلة بحثية
  • Researchers (عدة): كل واحد يبحث عن سؤال بالتوازي
  • Synthesizer: يجمع النتائج ويزيل التكرار
  • Writer: يكتب التقرير النهائي
  • Reviewer: يراجع الدقة والثغرات ويرجع للحلقة
  • API + UI: FastAPI + واجهة بسيطة

2. التنفيذ المتوازي

استخدم asyncio.gather لتشغيل الباحثين بالتوازي وضاعف السرعة.

import asyncio async def run_researchers(questions): # تشغيل كل الباحثين في نفس الوقت results = await asyncio.gather(*[research(q) for q in questions]) return results

3. حلقة المراجعة

def write_with_review(synthesis, max_rounds=3): draft = writer(synthesis) for i in range(max_rounds): feedback = reviewer(draft) if feedback.approved: break draft = revise(draft, feedback.notes) return draft

4. التخزين والواجهة

  • PostgreSQL: تخزين التقارير وتاريخ الطلبات
  • Redis: تخزين الحالة أثناء التنفيذ (تتبع تقدم المهمة)
  • WebSocket: بث تقدم الوكلاء للمستخدم لحظياً

5. خطوات التنفيذ (4 أسابيع)

الأسبوع 69: البنية + Planner
هيكل المشروع، Planner يقسّم الموضوع، وResearchers أولية على مصدر واحد.
الأسبوع 70: التوازي + البحث
بحث ويب متوازٍ، Synthesis، وحلقة مراجعة أساسية.
الأسبوع 71: API + تتبع
FastAPI + WebSocket للتقدم + تخزين النتائج في PostgreSQL.
الأسبوع 72: الاختبار + النشر
اختبارات للوكلاء، Dockerize، ونشر على AWS مع واجهة أمامية بسيطة.

6. التمارين

تمرين: تقرير عن شركة
أدخل اسم شركة واجعل النظام ينتج تقريراً عن منتجاتها ومنافسيها وأدائها.

  • نظام بحث آلي بفريق وكلاء يعمل على موضوع حقيقي
  • بحث متوازٍ (عدة أسئلة معاً) + حلقة مراجعة
  • API منشور + تتبع تقدم لحظي
