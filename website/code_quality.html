الأسابيع 89-92: نظّم مشاريعك كقاعدة كود احترافية جاهزة للمعاينة

← العودة إلى الرئيسية

المشاريع الجيدة تُكتب مرة، لكن المشاريع الاحترافية تُهذَّب. في هذه الأسابيع تراجع كل مشاريع السنة الأولى وتعاملها كأنها قاعدات كود سيُعرض عليها في المقابلات.

1. إعادة الهيكلة (Refactoring)

  • قسّم الملفات الكبيرة: routers / models / services / schemas
  • استخرج الدوال المكررة (DRY)
  • سمِّ الأشياء بوضوح (نِيّة في الاسم)
  • أزل الكود الميت والمعلق
  • أضف type hints كاملة

2. الأدوات الآلية

# التنسيق والفحص pip install ruff black mypy ruff check . # لنت وقواعد black . # تنسيق تلقائي mypy app/ # فحص الأنواع # خطاف ما قبل الالتزام pip install pre-commit
# .pre-commit-config.yaml repos: - repo: https://github.com/astral-sh/ruff-pre-commit rev: v0.4.0 hooks: - id: ruff - repo: https://github.com/psf/black rev: 24.4.0 hooks: - id: black

3. اختبارات لكل مشروع

# مثال: اختبار endpoint from fastapi.testclient import TestClient from app.main import app client = TestClient(app) def test_chat_returns_200(): r = client.post("/chat", json={"q": "مرحبا"}) assert r.status_code == 200 def test_chat_rejects_empty(): r = client.post("/chat", json={"q": ""}) assert r.status_code == 422

4. CI/CD لكل مشروع

أضف GitHub Actions لكل مشروع: يعمل ruff + tests عند كل pull request، وينشر تلقائياً عند merge على main.

name: CI on: pull_request: push: branches: [main] jobs: quality: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: actions/setup-python@v5 with: { python-version: '3.11', cache: pip } - run: pip install -r requirements-dev.txt - run: ruff check . - run: pytest --cov=app --cov-fail-under=80

5. التوثيق + README

# README احترافي يحتوي: # المشروع: وصف من جملة واحدة ## المميزات: قائمة موجزة ## التقنيات: FastAPI, PostgreSQL, Qdrant... ## التشغيل: خطوات تشغيل محلياً ## النشر: رابط + كيف ## لقطات: صور أو مخططات ## سكريبت: هيكل المجلدات

6. التمارين

تمرين 1: هيكلة مشروع
أعد هيكلة أفضل مشروع لديك ببنية modلار نظيفة + type hints + ruff خالٍ من الملاحظات.
تمرين 2: تغطية 80%
ارفع تغطية الاختبارات لمشروعك إلى 80%+ وأضف CI يعمل عند كل PR.
