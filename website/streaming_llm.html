Streaming — استجابات LLM في الزمن الحقيقي

الأسبوع 64: بث الإجابات كلمة بكلمة لتجربة استخدام أفضل

← العودة إلى الرئيسية

استدعاء LLM عادي ينتظر الرد كاملاً (قد يأخذ 10-30 ثانية). Streaming يعيد النتيجة قطعة قطعة — فيرى المستخدم الكلمات تظهر تدريجياً، فيشعر أن النظام حي وسريع.

1. البث مع OpenAI API

from openai import OpenAI client = OpenAI() def stream_chat(messages): stream = client.chat.completions.create( model="gpt-4o", messages=messages, stream=True ) for chunk in stream: if chunk.choices[0].delta.content: yield chunk.choices[0].delta.content

2. البث عبر FastAPI (SSE)

Server-Sent Events تسمح للخادم بدفع بيانات للمتصفح عبر HTTP بسيط (أحادي الاتجاه).

from fastapi import FastAPI from fastapi.responses import StreamingResponse import json app = FastAPI() @app.post("/chat") async def chat(question: str): def generate(): for token in stream_chat([{"role": "user", "content": question}]): yield f"data: {json.dumps({{'token': token}})}\n\n" return StreamingResponse(generate(), media_type="text/event-stream")
💡 لماذا SSE بدل WebSocket؟ للبث أحادي الاتجاه من الخادم إلى المتصفح (حالة chat العادية) SSE أبسط ويعمل عبر HTTP العادي مع CORS بسهولة.

3. البث في LangChain / LangGraph

from langchain_core.output_parsers import StrOutputParser from langchain_openai import ChatOpenAI llm = ChatOpenAI(model="gpt-4o", streaming=True) chain = llm | StrOutputParser() async def stream_question(question): async for token in chain.astream(question): yield token

4. الاستخدام العملي في الوكلاء

  • أظهر حالة الوكيل: "جاري البحث..." ثم "جاري الكتابة..." أثناء التنفيذ
  • بثّ إجابة RAG كلمة بكلمة فور وصولها
  • أرسل أحداث التقدم عبر WebSocket لمستخدم واحد
⚠️ تذكر: لا تعرض النتيجة الجزئية للمستخدم قبل أن يقرها الوكيل (قد تتغير بعد المراجعة). في أنظمة المراجعة، اجمع أولاً ثم انشر.
