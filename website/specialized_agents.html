وكلاء متخصصون — Research و Review

الأسابيع 65-68: Planner، Researcher، Reviewer، Coding Agents

← العودة إلى الرئيسية

لا تكتفِ بوكيل عام. ابنِ وكلاء متخصصين لكل دور: من يخطط، من يبحث، من يراجع، من يكتب كوداً. معاً يشكلون فريقاً متكاملاً يحاكي طريقة عمل المهندسين الحقيقيين.

1. Planner Agent — المخطط

يحوّل المهمة الكبيرة إلى خطة خطوات واضحة قبل أي تنفيذ.

def planner(task): plan_prompt = f""" قسّم المهمة التالية إلى خطوات تنفيذية واضحة (3-6 خطوات): المهمة: {task} لكل خطوة: الهدف + المدخلات + المخرجات. """ return llm(plan_prompt) # → قائمة خطوات منظمة

2. Researcher Agent — الباحث

يجمع المعلومات من مصادر (ويب، قاعدة بيانات، مستندات) ويعيدها منظمة بالاستشهادات.

# أدوات الباحث: بحث ويب + قراءة صفحات tools = [web_search_tool, fetch_page_tool, vector_search_tool] def researcher(question, context): findings = [] for tool in tools: results = tool.invoke(question) findings.extend(results) return { "answer": summarize(findings), "sources": [r.source for r in findings] }

3. Reviewer Agent — المراجع

يراجع ناتج الآخرين بعين ناقدة: تحقق من الدقة، الثغرات، والأسلوب. يرفع الجودة بشكل هائل.

def reviewer(draft): review_prompt = """ راجع التقرير التالي كخبير صارم: 1. هل المعلومات دقيقة؟ حدد أي أخطاء. 2. هل هناك ثغرات في التغطية؟ 3. هل الأسلوب واضح؟ 4. اقترح تحسينات محددة. التقرير: {draft} """ return llm(review_prompt.format(draft=draft))
💡 حلقة الجودة: أنشئ حلقة: Writer يكتب → Reviewer يراجع → Writer يعدّل بناءً على الملاحظات → Reviewer يوافق. كرّر حتى "معتمد".

4. Coding Agent — وكيل الكود

يكتب وينفّذ ويصلح كوداً في بيئة معزولة.

def coding_agent(spec, existing_code): # 1) اكتب الكود حسب المواصفات code = generate_code(spec, existing_code) # 2) نفّذه في بيئة آمنة وامسك الأخطاء output, error = run_in_sandbox(code) if error: # 3) أصلح الخطأ وكرر return coding_agent(spec + f" (الخطأ: {error})", code) return {"code": code, "output": output}

# تدفق: Planner → Researcher → Writer → Reviewer → Coding (إن لزم) state = {"task": task} state.update(planner(state["task"])) state["findings"] = researcher(state) state["draft"] = writer(state["findings"]) state["review"] = reviewer(state["draft"]) if state["review"].approve: return state["draft"] else: state["draft"] = revise(state["draft"], state["review"])

6. التمارين

تمرين 1: فريق تقرير
وكيل باحث + كاتب + مراجع: اجمع معلومات عن موضوع واكتب تقريراً محكماً.
تمرين 2: وكيل مبرمج
وكيل يكتب دالة بسيطة، ينفذها، ويصلح أخطاءها تلقائياً حتى النجاح.
